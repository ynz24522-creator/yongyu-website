# 画册数据转录与疑似笔误说明

网站数据全部逐条转录自《永裕光电产品画册 (V0)》（33 页，A4，2024-07 制作），共 **23 个封装系列、35 张参数表、131 个型号、268 行参数**。

## 一、转录原则

1. 参数表数值**原样保留**，不做单位换算、四舍五入或推断；缺值显示为「—」。
2. 已按画册版面坐标校正列归属，因此表头为合并单元格（如 `Min. Max.`）或数值跨列合并的情况不会串行。
3. **中文界面**会把发光颜色与备注译为中文（蓝光/绿光/反极性/带齐纳…），英文界面保留原文；型号与数值始终原样显示。
4. 仅在两处对叙述性文字做了明显排版错误的清理：P3 中文简介的重复标点「、，」与重复字「企企业业愿愿景景」；里程碑中的 `IATF14949` 按正确写法 `IATF16949` 呈现。参数表内一律不改。

- 发展历程时间线：画册 P5 的年份与事件在文本层是错位的（版面为左右交错排列），已按版面坐标重新对应为 2008 深圳创立 / 2015 月产能 1000KK / 2017 ISO9001 与广东省高新技术企业 / 2020 广西工厂投产（80 条线）与国家级高新技术企业 / 2021 月产能 2500KK 与广东半导体委员会成员 / 2022 广东优秀企业与 IECQ QC080000、ISO14001 / 2023 汕头工厂投产（月产能 4000KK）与 IATF16949。
