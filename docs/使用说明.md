# 永裕光电官网 · 使用与维护说明

> 本文件位于仓库 `docs/` 目录，描述的是**站点仓库本身**的结构与维护方式。

- 仓库：<https://github.com/ynz24522-creator/yongyu-website>
- 线上地址：<https://ynz24522-creator.github.io/yongyu-website/>（在仓库 Settings → Pages 选择 `main` / `(root)` 后生效）
- 仓库根目录即网站根目录，仓库中除 `README.md`、`docs/` 与 git 配置文件外的所有内容都会随站点一起发布。

## 一、网站形态

纯静态站点（HTML + CSS + 原生 JavaScript），**无构建步骤、无依赖、无外部 CDN**，共 8 个页面：

`index.html` 首页、`about.html` 关于我们、`products.html` 产品中心、`product.html` 系列详情页、`applications.html` 应用领域、`strength.html` 实力与认证、`contact.html` 联系我们、`inquiry.html` 询价清单。

## 二、本地预览与更新发布

- **本地预览**：把仓库克隆或下载到本地后，双击 `index.html` 即可浏览（默认中文）。也可用任意静态服务器预览。
- **更新发布**：修改文件 → `git add -A` → `git commit -m "说明"` → `git push`，GitHub Pages 会自动重新发布，通常 1 分钟内生效。
- **直接上传到其它主机**：把仓库文件（不含 `.git/` 目录）上传到网站根目录即可，无需服务端配置。
- 说明：部分浏览器在 `file://` 协议下会禁用 `localStorage`，此时语言偏好与询价清单只在当前页面内有效；部署到 http(s)（含 GitHub Pages）后功能完整。代码对此已做降级处理，不会报错。

## 三、常见修改位置

| 想改什么 | 改哪里 |
| --- | --- |
| 界面文案（中/英） | `assets/js/i18n.js`：`zh` / `en` 两个字典，页面用 `data-i18n="键名"` 引用 |
| 产品参数（型号、颜色、各项数值） | `assets/js/product-data.js` 中的 `series[].tables[].rows` |
| 联系方式、发展历程、认证、公司简介、愿景使命、关键数据 | `assets/js/product-data.js` 中的 `contacts` / `milestones` / `certifications` / `company` / `stats` |
| 页面版块增删 | 对应的 `.html` 文件（页头、页脚、询价抽屉为 8 个页面公用，需同步修改） |
| 图片替换 | 直接覆盖 `assets/img/` 下的同名文件（建议保持文件名与尺寸） |
| 顶部与页脚 logo | `assets/img/logo.png`（透明底 PNG，由画册封面 logo 抠底生成） |
| 画册下载文件 | `assets/download/yongyu-catalog-v0.pdf` |
| 颜色、间距、圆角等视觉变量 | `assets/css/style.css` 顶部的 `:root` 变量（主色 `--brand`、LED 红 `--led-red`、LED 绿 `--led-green`） |

## 四、功能说明

- **语言切换**：右上角「中文 / EN」。默认中文，选择会记入 `localStorage`（键 `yy_lang_v1`）；分享链接可加 `?lang=en` 直接打开英文版。
- **产品检索**：产品中心支持按产品家族、发光颜色筛选，并按型号或关键字搜索（例如 `YY-KMTABL`、`0603`、`RGB`）。搜索结果可直接跳到对应系列并把该型号高亮。
- **询价清单**：任意参数表每行可「加入询价」，也可「本表全部加入」；清单保存在 `localStorage`（键 `yy_inquiry_v1`）。在询价页面填写公司名、联系人、数量与备注后，点「生成询价邮件」会调用默认邮件客户端，收件人为 `sales@yongyuled.com`，也可用「复制邮件内容」手动发送。
- **响应式**：手机端导航收成抽屉菜单，参数表自动变为「字段—数值」卡片流；表格在宽屏下为双行表头并支持横向滚动。
- **打印**：参数页可直接打印（自动隐藏导航、按钮与询价控件）。

## 五、从画册重新生成数据（可选，需要本机开发脚本）

仓库中**不包含**生成脚本；它们保存在本机开发目录 `work/` 下（不在本仓库内）。当有新版画册时，可按顺序运行：

```bash
PY=/Users/zhangyunan/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
NODE=/Users/zhangyunan/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node
cd work
$PY dump_tables.py        # 1. 抽取画册所有表格（原始）
$PY extract2.py           # 2. 结构化产品参数表 -> tables.json
$PY build_assets.py       # 3. 提取并转换图片 -> assets/img
$PY build_data.py         # 4. 生成 assets/js/product-data.js
$PY build_site.py         # 5. 生成 8 个 HTML 页面
$PY verify.py             # 6. 静态校验：链接、i18n 键、图片、与 PDF 数据逐行比对
$NODE dom_test.js ../outputs/yongyu-website   # 7. 渲染与交互行为校验
```

若画册只有少量改动，直接编辑 `assets/js/product-data.js` 更快。

## 六、已知限制

- 无后端：询价通过邮件发送，不做表单落库；如需留言入库或在线报价，需要另加服务端或第三方表单服务。
- 参数以画册 V0 为准：所有数值逐条转录，未做换算或推断。画册本身的疑似笔误见 `docs/画册数据与笔误说明.md`。
- 画册目录列出的**照明 LED**（2016/2835/3030/3014/3020/5050）与**光传感**在正文中没有参数页，网站按「开发中」呈现，未虚构任何数据。
- 图片均取自画册：对应关系见 `assets/img/manifest.json`（含来源页与用途）。若某张照片的裁切或内容不合预期，替换同名文件即可。
